# 🧠 Crypto Aggregator Dashboard

This is a personal wealth management dashboard that aggregates and analyzes portfolio data across traditional and crypto holdings, including:

- 📈 Real-time valuations from CoinGecko and Yahoo Finance
- 🧾 Tax estimators for unrealized gains
- 📊 Risk metrics including Sharpe Ratio and performance over time
- 🧠 GPT-generated internal insights
- 📥 Exportable PDF reports with charts and summaries

Deployed via [Streamlit Cloud](https://streamlit.io/cloud)
